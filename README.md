# mining-rag



RAG system for mineral processing, built by someone who works at a mine

## Troubleshooting log



* Docker Desktop: 'Virtualization not detected' → AMD-V disabled in BIOS + WSL/Virtual Machine Platform missing → enabled AMD-V, ran wsl --install, rebooted
* options after the image name go to the program inside, not to docker
* exit error code 137 = container was force-killed
